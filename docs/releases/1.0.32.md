## What's New

- **Reorganized personal settings:** General, HUD, Loading, Recording and Advanced categories, with scrolling, clearer tooltips and a compact layout for smaller screens. Testing overrides are visibly marked. Existing preferences are preserved.
- **Survival and command permissions:** Rooms always creates Survival worlds. With Allow Cheats off, saved-world, operator and LAN permission flags can no longer grant player cheat commands, including `/seed`. Unrelated singleplayer worlds and Atum defaults are left unchanged.
- **Adult animal guarantee:** Minimum Nearby Animals now counts adults only and adds adults when needed. Existing babies are left alone.
- **Loading logo fix:** Chunk-progress colors no longer show through the logo's transparent areas. Reduced redundant drawing while keeping the same progress and position presets.
- **Lower bookkeeping overhead:** Reduced natural-spawn counter allocations and repeated tournament bracket and standings calculations without changing spawn outcomes or tournament rules.

All runners should update to **ZSG Rooms 1.0.32** for the same rule fixes. **Replay Viewer remains 0.5.0** and ReplayMod remains **1.16.1-2.6.27**. No room-relay deployment is required.
