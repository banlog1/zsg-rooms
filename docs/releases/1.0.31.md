## What's New

- **Correct seed-bank spawns:** Rooms now receives the filter's intended structure coordinates instead of searching for another nearby structure. This fixes cases where a village seed sent runners to the wrong village without its blacksmith. Existing bank entries have been backfilled. Spawn preparation happens before chunk preloading, and resets retain the same target. Bank launches with missing or invalid coordinates are rejected.
- Added **No Temple Hostile Spawns** in Game Rules. Enabled in Standard presets and disabled in Raw, it prevents natural hostile spawning inside desert temples and their treasure chambers on any seed type, including AA. Existing mobs are not removed, and outside mobs can still walk in.
- Added **Race Format** with 1-20 shared seeds and a separate finisher limit, both defaulting to one. Runners advance independently; placements use one real-time clock including loading and resets. Multi-seed skips add 30 minutes. Single-seed forfeits remain a loss without a penalty. Increase Finishers to allow more placements.
- Added optional **Tournaments**: single-elimination brackets with best-of 1/3/5/7 matches, player-selected byes and an interactive bracket, or points tournaments with configurable rounds and placement scores. Only the current bracket pair races. Keep the host's game open; tournament progress cannot resume after restarting Minecraft.
- Added the **ZSG loading indicator**, with the clean-pixel logo filling over the chunk-progress square. Choose ZSG or Vanilla in Loading Screen settings; position presets remain available. The logo works without the optional artwork pack.
- Improved **Replay Viewer** indexing and cache reuse for chest contents, milestones and player data. Quick mode now shows recorded held items. Added optional experimental **Seek batching** for normal playback. It remains off by default; speed gains are not established and lighting may differ.
- Automatic sequence advances and same-seed resets stay in one replay. Recorded chest contents remain available, but unopened-loot prediction is disabled for multi-seed recordings because that metadata currently supports one seed per file.

**All runners must update ZSG Rooms to 1.0.31.** Rooms using bank filters or the temple spawning rule will not start with guests missing the spawn-rules update. Update the optional **ZSG Replay Viewer to 0.5.0**; ReplayMod remains **1.16.1-2.6.27**. No room-relay deployment is required.
