## What's New

**ZSG Rooms 1.1.2 + Replay Viewer 0.6.1 (unchanged)**

- **Simpler rooms:** Create a room straight from the menu and share its code.
  Friends only need the code to join through the default relay. New rooms use
  ZSG Rooms Mode, Standard ZSG Rooms rules with cheats off, one seed, one
  finisher and 10 player places. Change these from the lobby before starting.
- **Cleaner room options:** Manual seed entry appears only when Manual Seed
  is selected. Hosts can adjust player capacity from the lobby; races and
  active tournaments keep it locked.
- **Settings import:** Copy compatible Minecraft and StandardSettings options
  from another instance. Nearby MultiMC/Prism instances show their saved names
  and Minecraft versions when available. Choose categories and review changes
  before applying them. Open the small import button beside ZSG Rooms on the
  title screen, or find it under Settings > General.
- **Saved settings:** Keep named settings snapshots, rename or export them,
  and preview a restore from the Saved Settings tab. Imports keep an undo
  backup and recover interrupted changes without modifying the source instance.
- **Interactive tutorial:** Choose No, A quick one, or Yes, full on first
  launch. Try recording levels, camera rates, rules and other options in a
  practice tour without changing your settings or connecting to a room.
  Reopen it through Settings > General > Guided tutorial.
- **Easier setup:** Fresh install packs start with music at 0%. The standard
  pack remains available, with a separate Windows ToolScreen variant and
  one-time setup instructions above. Java 17 is recommended, not required by Rooms.
- **Connection handling:** Room connections no longer block the menu. Cancel
  or retry failed connections, with clearer messages for missing/full rooms
  and a separate custom-relay settings screen linked to the setup guide.

**After importing or restoring settings, close Minecraft completely and
relaunch the instance.** Returning to the title screen is not enough. Only
supported settings are copied; accounts, worlds, mods and launcher/JVM settings
are left alone. Shared StandardSettings files are never modified.

Existing players can update Rooms in place. Replay Viewer remains **0.6.1**
and ReplayMod remains **1.16.1-2.6.27**. Importing either pack creates a fresh
instance; it does not replace an existing one. No relay deployment is needed.
